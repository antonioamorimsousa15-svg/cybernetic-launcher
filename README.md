# CYBERNETIC LAUNCHER

Launcher de Minecraft: Java Edition para Android, só OpenGL. Criador: shoyoo.mc.

GitHub: aba Actions > "Build CI" > Run workflow. O APK sai em Artifacts. Requer JDK 21.
